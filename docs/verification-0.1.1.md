# 0.1.1 功能验收记录

[项目首页](../README.md) · [功能手册](features.md) · [发布工作流](https://github.com/oldxiaoxiao/xiao-pan-auto-save/actions)

本次验收使用隔离的临时数据库和本地测试文件。自动测试覆盖业务行为和模拟第三方响应；只有实际执行的原生/容器检查才计为平台验证，不将外部依赖和未实现驱动写成“全部可用”。

## 功能覆盖

| 功能 | 验证方式 | 状态/边界 |
|---|---|---|
| 任务/账号/设置 CRUD、排序、复制默认 | API 和表单契约测试 | 自动验证覆盖 |
| 追更差集、筛选、子目录、命名、只读试跑 | 假驱动与引擎测试 | 自动验证覆盖 |
| 全局/独立调度、三种执行方式、重试预算 | 调度和服务测试 | 自动验证覆盖 |
| 夸克协议、分页、转存、失效链接、账号检查 | 模拟 HTTP | 未用真实账号转存或签到 |
| 搜索协议、多实例、去重、部分失败 | 模拟 PanSou/kkso/CloudSaver 响应 | 公开源可用性不保证 |
| 24 种通知协议、开关及错误处理 | 模拟 HTTP/SMTP | 未向私人通知渠道发送消息 |
| 内置下载、停止、历史、到位检查、重下竞态 | 下载/账本/API 测试 | 自动验证覆盖；不支持断点续传 |
| Aria2 投递/结果/暂停/停止/重下 | 模拟 RPC + 可选真机测试 | 真机执行结果见下面构建记录 |
| Emby 刷新 | HTTP 接线测试 | 不代表真实媒体库扫描完成 |
| Token API、迁移、备份 | API 和临时 SQLite 测试 | 自动验证覆盖 |
| 管理鉴权与静态路径限制 | 密码/会话/Basic/Token/越界回归 | 发布前发现并修复 |
| 桌面路径、单实例、启动/退出 | 系统文件锁与真实本地子进程 | 自动验证覆盖 |
| Windows 下载命名 | 保留名与尾随字符回归 | 自动验证覆盖 |
| 迅雷/123/百度/阿里/115/天翼/移动/AList | `supported=False` 注册表 | 尚未实现 |

## 可用性结论的含义

共享业务的自动测试通过，说明已覆盖的应用行为符合测试契约。网盘 Cookie、配额、分享有效性、搜索站连通性、通知凭证及真实 Emby 需要在使用环境验证。客户端图形界面能启动不等于已在所有系统、所有网盘账号和所有通知渠道验证。

## 后续验证重点

客户端托盘/休眠唤醒/更新恢复尚未交付；超长 Windows 路径、异常挂载、透明压缩文件系统以及大规模 Aria2 队列继续属于已知验证边界。相关优先级见[后续路线](roadmap.md)。
