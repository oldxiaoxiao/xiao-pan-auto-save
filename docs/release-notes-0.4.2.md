# 小盘自动转存 0.4.2 · 任务页不再"点了没反应"

> 一个修复版，动的是两处**用户点了却什么都没发生**的地方：
>
> 1. 任务页一旦有过未保存的修改，点其它任务、点「＋ 新建任务」都会被静默拦下——界面像卡死；
> 2. 「剪贴板导入」在桌面客户端里几乎必然失败（剪贴板 API 要求安全上下文），留下一个死按钮。

## 为什么要做

这类缺陷的共同点是**不报错、不留痕**：程序其实"照章办事"了，但用户看到的只是"我点了，没反应"。
尤其在桌面客户端窗口里，一条 3 秒就消失的提示几乎等于没提示，于是整个页面像是坏掉了。

## 改了什么

### 1. 丢草稿前先问一句，不再闷着拦下

| 动作 | 之前 | 现在 |
|---|---|---|
| 点其它任务行 / 收起当前行 | 有未保存修改时只弹一条 3 秒 toast，然后什么也不做 | 弹确认框：**丢弃并继续 / 返回继续编辑**，并点名是哪一份草稿 |
| 点「＋ 新建任务」 | 被同一道门静默拦下 | 同上，点击必然有结果 |
| 复制为新任务 / 导入链接 | 同上 | 同上 |
| 表单「取消」 | 直接丢弃 | 直接丢弃（用户已明说不要这份草稿，不再多问一次） |
| 置顶 / 置底 | 只弹 toast | 单独口径：点名"调整排序会用服务端的值重建这一行" |

触发这道门比想象中容易——展开详情后误拨一个开关（下载到本地、转存成功时通知我、子目录过滤等）
就算"有未保存的修改"。所以把它做成明确的二选一，而不是一句看不见的提示。

### 2. 导入链接不再依赖剪贴板

桌面客户端跑在 `http://127.0.0.1:随机端口`，各家 WebView 对 `navigator.clipboard.readText()` 的判定
并不一致（WKWebView 尤其常直接拒绝），原实现失败时只报一句"需 https 或用户授权"，等于死按钮。

- 按钮改为「📋 导入链接（剪贴板 / 手动粘贴）」，不再承诺"读剪贴板"这件做不到的事；
- 先试剪贴板，**读不到或读到的不是夸克链接就原地弹出粘贴框**（多行输入 + 实时校验，
  格式不对直接说"没找到夸克分享链接，形如 https://pan.quark.cn/s/..."）；
- 剪贴板能用的环境里依旧自动读取优先，手动框只在读不到时才出现。

## 验证

- 真实 pywebview 窗口 + 生产构建（`frontend/dist`）实测，不是 mock：
  - 拨开关后点下一行：`formIndex` 停在原行、只出现一条 toast（**修复前的复现**）；
    修复后弹出确认框，点「丢弃并继续」确实切到目标行，点「返回继续编辑」原地不动、草稿还在。
  - 点「导入链接」→ 弹出「手动导入链接」框 → 粘贴 `https://pan.quark.cn/s/...` 提交后，
    新建表单的分享链接字段确实带上了该值。
  - 干净状态（无未保存草稿）下，切行 / 新建 / 取消仍是一次点击直接响应，不会多弹框。
- 前端：`npm run typecheck` 通过、`npm run lint:check` **0 error**、prettier 全过；
  `TasksView.vue` 单文件 warning 数 34 → 34（未破基线）。
- 后端：ruff 通过；`TZ=UTC python -m pytest backend/tests -q` → **636 passed / 1 skipped**
  （CI 用 UTC 时区跑；与 0.4.1 持平——本版未动后端）。

## 升级注意

1. 本版只改前端交互与文案，**未改动表结构与接口**，升级向下兼容。
2. 桌面端升级仍是"下载新包 → 替换程序"，数据目录不受影响。
3. 本地 `release/` 目录已清空旧版本（0.1.1 / 0.2.0）的构建产物：那些包早已过时，
   当前版本是唯一的下载来源，需要哪个平台重新跑一次 `scripts/build_desktop.py` 即可。

## 已知边界（本期未做）

- **前端没有自动化测试框架**，CI 只覆盖 typecheck / lint / build 与后端 pytest。
  本次两处都是交互行为，靠上面那份真实客户端实测作为证据，**CI 无法防回归**——
  改到 `TasksView.vue` 的编辑态切换逻辑时，请照着上面的步骤手动走一遍。
- 剪贴板仍只能读文本、且只认夸克链接（目前只有夸克驱动是 `supported`）。
- 不做签名与公证（产品决定，非待办）：校验靠发布包自带的 `SHA256SUMS`，信任靠源码公开。
  首次打开的系统拦截属预期行为，绕过步骤见[客户端指南](desktop.md)。
