## 0.2.0 · 2026-10-10

本期主题为 **「可信」**：让用户敢长期放着不管。完整说明见 [发布说明](release-notes-0.2.0.md)。

### 新增与完善

- 总览仪表盘（今日 / 近 7 天视图，待处理直达）。
- 命名模板库（内置剧集 / 综艺 / 动画 / 电影模板，试跑展示不匹配样本，支持个人模板）。
- 备份 / 恢复与脱敏导出（不含凭据 / 含凭据两种模式，版本兼容校验，恢复前自动备份）。
- 凭据本地加密存储（Fernet 加密入库，密钥文件权限 `600`，明文自动迁移）。
- 账号凭据到期预警（"需更新"徽标 + "需处理"通知，24h 不重复骚扰）。
- 任务健康度与失败归因（正常 / 待处理 / 已停摆，待处理聚合视图）。
- 通知分级与免打扰（需处理 / 仅告知，免打扰时段聚合摘要）。
- 磁盘与配额运行预检、网盘限流指数退避。
- 账号容灾切换（主账号不可用自动切备用账号，切换不改保存目录与命名）。
- 下载队列持久化与内置断点续传（Range 续传，`.part` 接管，重启可恢复）。
- 对话式助手增强（复合意图、默认最优值、中文化动作卡、保存目录选择器、统一时间格式）。

### 升级注意

1. 首次启动会自动加密历史明文 Cookie；升级前建议先用新备份功能导出"不含凭据"备份。
2. 含凭据备份含加密 Cookie，请设置访问口令；旧 `data/*.db` 手动拷贝可能仍含明文，请尽快迁移。
3. 登录后默认进入总览页；通知分级默认将既有渠道归为"仅告知"，"需处理"类提醒保持开启。

### 已知边界

FR-11（SQLite WAL 与写保护）按规划推迟至 v0.3 / v0.4；仍为单网盘（夸克）可用；桌面端无托盘 / 自启 / 自动更新 / 远程模式，包未签名公证。

## 0.1.1 · 2026-10-08

本次将现有自动转存/追更应用整理为共享业务核心、Compose/Web 和 Windows/macOS 客户端三种发行形式。

### 新增与完善

- Windows x64、macOS Apple Silicon/Intel 原生窗口、独立本地服务、用户数据目录、自动登录和单实例限制。
- 管理密码实际保护账号、任务、设置、日志和 Token 接口；支持浏览器会话与 HTTP Basic，外部 Token API 保持独立。
- 固定版本 Compose 镜像、默认本机绑定、构建上下文排除私人数据、锁文件安装、三平台编译与 Release 附件校验和。
- README 重写为项目介绍，拆分功能、配置、部署、客户端、开发、路线、升级和验收文档。

### 修复

- 修复 `WEBUI_PASSWORD` 只声明配置但未执行鉴权的问题。
- 阻止静态资源路由通过相对路径读取前端目录外的文件。
- 默认下载目录随 `DATA_DIR` 变化，避免桌面下载写入安装目录。
- Windows 设备保留名称及尾随点/空格被归一化，减少文件创建失败。
- Vite 开发代理保留浏览器 Host，避免同源保护误拒绝登录和管理写请求。
- 修复已有前端格式检查失败的文件。
- 配置导入改为单一事务，保留其他网盘账号，成功后撤销旧作业并重建调度，拒绝格式错误的插件配置。

### 升级注意

1. Compose 默认监听从全部网卡改为 `127.0.0.1`。局域网访问需明确设置 `WEBUI_BIND=0.0.0.0`，并设置密码。
2. 配置过 `WEBUI_PASSWORD` 的部署现在会要求登录；外部脚本继续使用其独立 Token。
3. 网页新建、外部 add API 和整行 PUT 的 `auto_download` 默认开启；不希望落盘时明确关闭。已有任务不会批量改写。旧配置导入保留其原有下载选择。
4. 网页新建默认对分享子目录按集数/画质过滤；不需要时关闭“子目录也按集数/画质过滤”。已有任务不改变。
5. 新建任务只使用执行方式控制是否自动跑；“停用”用于已有任务临时暂停。设置页的新建默认只影响之后新建的任务。
6. 任务整行 PUT 会补齐省略字段；只修改部分字段请使用外部 update API。
7. 桌面版默认使用新的用户数据目录；旧源码/容器数据不自动迁移，升级程序也不搬运下载文件。
8. 内置下载中断后重新下载，不支持跨重启断点续传；暂停/继续只由 Aria2 提供。

### 已知边界

当前只实现夸克驱动；其余网盘是未实现骨架。客户端无托盘、自启、自动更新和远程模式；包未进行发行者签名/Apple 公证。公开搜索源及真实网盘、通知和媒体库依赖由各自服务决定，验证范围见[验收记录](verification-0.1.1.md)。
