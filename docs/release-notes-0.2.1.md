# 小盘自动转存 0.2.1 · 省心下载

> 主题：**把「下载慢」和「配置门槛」两件麻烦事收掉，并让下载器的选择对用户透明**。

## 新增与改进

- **Aria2 自动启动，免手工安装**：下载模式选 `aria2` 后，程序会自动拉起本机的 aria2（带 RPC，只监听 `127.0.0.1`）；没填 RPC 地址就自动用 `127.0.0.1:6800`。用户不必知道 RPC 是什么，也不用自己下载、解压、配置 aria2c。
- **一键安装 aria2c**：本机没装 aria2c 时，下载设置页一个按钮自动装好——Windows 取官方包、macOS 走 Homebrew、Linux 用系统包管理器。客户端用户不再需要手工安装。
- **下载器不再「静默降级」**：设置页与下载页显示**当前实际使用的下载器**（aria2 / 内置）；aria2 起不来时给出具体原因并临时改用内置下载器，界面与日志都能看到原因，不会再出现「以为在用 aria2、其实一直在用慢速内置下载器」的情况。下载列表新增「下载器」列。
- **本机模型免 API Key**：Ollama、LM Studio 等本机模型不需要 Key，勾选「免 API Key」后可不填即保存、测试与使用；选择 Ollama 预设会自动勾上。勾选后请求不再携带 `Authorization` 头。远端商用模型不受影响，默认仍要求 Key。

## 修复与细节

- Aria2 未配置地址时不再直接判定「不可达」，而是按默认本机地址尝试连接 / 拉起。
- 远端 aria2 地址（非 `127.0.0.1` / `localhost`）不可达时，不会在本机误起一个 aria2，只如实报错。
- 程序只托管**自己拉起**的 aria2 进程，退出时回收；用户已有的 aria2 不受影响。
- 「未配置 API Key」的报错文案补充了本机模型的处理方式，指向正确动作。

## 升级注意

1. **既有 AI 配置不受影响**：新增的「免 API Key」默认关闭，已配置 Key 的服务行为完全不变。
2. **Aria2 地址留空即可用**：此前必须手填 RPC 地址；现在留空会自动使用 `127.0.0.1:6800` 并按需拉起。已手工配置过的地址保持原样，优先连接现有 aria2。
3. **自动拉起只监听本机**：拉起的 aria2 带 `--rpc-listen-all=false`，不会把 RPC 暴露到局域网。
4. 本版未改动数据库主键结构；新增 `ai_provider.api_key_required` 列由启动自动补齐（存量行默认「仍需 Key」），升级向下兼容。

## 已知边界（本期未做）

- 桌面端仍未随包自带 aria2c 二进制（可联网一键安装，或沿用已有的 aria2）；后续可考虑随包分发。
- 桌面端无托盘 / 自启 / 自动更新；包未做发行者签名与 Apple 公证。
- 仍为单网盘（夸克）可用；其余网盘为未实现骨架。
