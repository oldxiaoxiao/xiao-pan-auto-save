# 小盘自动转存 0.3.2 · 挑到的文件，点一下就能找到

> 主题：**补齐客户端常驻的最后两块拼图**——选目录不用手敲路径，下完的文件点一下就能在文件管理器里现身。

## 下载目录改成「浏览出来」，不再是填空

此前设置页的下载根目录是一个纯文本框，只能手敲绝对路径：路径写错不报错（等到下载失败才暴露），Windows 的盘符、macOS 的 `/Users/<名>` 全凭记忆。

现在换成「浏览…」选择器（`DirPicker`），由后端拿本机真实目录给它喂数据：

| 后端接口 | 作用 |
|---|---|
| `GET /api/fs/roots` | 快捷入口：主目录、下载目录，以及 `/Volumes`、`/mnt`、`/media`（Windows 下自动枚举可用盘符） |
| `GET /api/fs/dirs?path=` | 列出该目录下的**子目录**（只列目录，按名称排序，含「是否可写」标记） |
| `POST /api/fs/reveal` | 在文件管理器里定位到该路径 |

- 列表走 `os.scandir`，**只挑目录**；无权限的条目静默跳过，不会因为一个读不了的目录让整个列表失败；条目超上限会截断并明确标注。
- 目录不可写会在选择器里挂「不可写」标签——比等到任务跑起来才发现写不进去更早一步。
- 路径依旧可以手敲（输入框保留），选择器只负责把正确的路径填进去，两条路都留着。

**前提要说清楚**：这些路径是**运行后端那台机器**上的路径。桌面客户端即用户本机；Compose 部署时后端在容器里，选择器列的是容器内的目录——这与下载根目录一贯的语义一致。

## 打开目录：下完的文件不再要靠搜索

下载页两张表（进行中、历史）的**目标路径**列都加了「打开目录」按钮，调用 `/api/fs/reveal` 在本机文件管理器里定位到该文件：

| 平台 | 行为 |
|---|---|
| Windows | `explorer /select,`，**选中文件本身** |
| macOS | `open -R`，在 Finder 中**选中文件** |
| Linux | `xdg-open` 打开所在目录（无「选中」语义），并给出提示说明这是平台能力所限 |

目标路径还不存在时如实报错（「文件或目录不存在」），不是点了没反应——这条边界恰好覆盖了「文件已被手动清理」的日常场景，省掉一次徒劳的搜索。

## 测试与验证

- 新增 `backend/tests/test_local_fs.py`（15 例）：按平台断言命令形状（含 `/select,` 与 `-R` 的差异）、假 `scandir` 的容错路径、传文件当目录返回 400、符号链接被解析后的 `parent` 值。
- 后端：ruff 通过，**600 passed / 1 skipped**。
- 前端：prettier 通过、eslint **0 error**、vue-tsc 通过。
- 真实 HTTP 冒烟（本地起服务 + curl，非 mock）：`/api/fs/roots` 返回本机快捷入口、`/api/fs/dirs` 正常列目录且 `/private/etc/hosts` 这类「传了文件」的情况返回 400 `不是目录`、`/api/fs/reveal` 对存在的文件返回 `{ok:true, select_supported:true}`、对不存在的路径返回 400。

## 已知边界（本期未做）

- 选择器只列本机真实目录，**不做网络邻居 / 网盘挂载点的特殊处理**；这些要先在系统里挂好。
- 仍无 macOS 沙盒授权处理：把下载目录选到受保护的位置（如桌面、文稿）时，首次写入可能被系统拦下，需要用户在系统弹窗里放行——这是系统行为，程序绕不过。
- **分发与更新基础**（版本检测、下载校验、升级前自动备份）尚未实现；签名与公证也未做，后续一旦做签名，**随包 aria2c 及其 dylib 必须一并签名**，否则 macOS 公证会失败。
- **FR-11（SQLite WAL 与写保护）**顺延至 v0.4。仍为单网盘（夸克）可用；桌面端不出 Linux 包，Linux 请用 Compose 的 aria2 profile。

## 升级注意

1. 本版仅新增接口与界面改动，**未改动数据库结构**，升级向下兼容。
2. Compose 用户：新的 `/api/fs/*` 接口能调通，但列的是**容器内**目录；仍建议直接填挂载好的宿主机路径。
