# 小盘自动转存 0.2.0 · 可信

> 主题：**让用户敢长期放着不管**。本期聚焦中断可感知、失败可归因、数据可恢复、凭据可加密。

## 新增能力（v0.2「可信」十项）

- **总览仪表盘**（首页）：今日 / 近 7 天视图——新增转存文件数、成功任务数 / 应跑任务数、待处理项数、下载完成量与失败量；"待处理"一键直达聚合视图。数据全部来自本地 SQLite，不上报任何外部服务。
- **命名模板库**：内置剧集 `SxxExx`、综艺按日期、动画连续编号、电影等模板，一键套用正则 + 替换 + 变量组合；套用前走试跑，不匹配的文件名单独列出；支持保存个人模板复用。
- **备份 / 恢复与脱敏导出**：一键导出备份，提供"不含凭据"与"含凭据"两种模式（含凭据文件界面明确警示）；恢复前自动备份当前数据，并校验版本兼容性，更高版本拒绝恢复。备份内容含任务、账号、设置、下载历史。
- **凭据本地加密存储**（安全底线）：账号 Cookie 经 Fernet 加密入库（密钥来自数据目录密钥文件，权限 `600`），日志与 API 响应禁止输出明文；启动自动迁移历史明文凭据，密钥丢失有明确重录路径。
- **账号凭据到期预警**：系统按可配置周期检查账号有效性，失效账号卡片显示"需更新"徽标并推送"需处理"级通知；24 小时内不重复骚扰；重贴 Cookie 后徽标清除并恢复调度。
- **任务健康度与失败归因**：任务行显示正常 / 待处理（失效链接、连续失败、账号异常）/ 已停摆；提供"待处理"筛选视图聚合异常任务与最近失败原因；失效分享归入待处理并支持"重新验证链接"。
- **通知分级与免打扰**：通知分"需处理"（失效、凭据过期、磁盘/配额不足、重试用尽）与"仅告知"（转存成功摘要）；支持免打扰时段（默认 23:00–08:00）内聚合为次日 1 条摘要；"仅告知"可按任务关闭。
- **磁盘与配额运行预检**：下载前校验目标盘可用空间 ≥ 待下文件总大小 × 1.1，不足则跳过并通知；转存前校验目标账号剩余容量；网盘连续限流时指数退避并暂停该账号任务。
- **账号容灾切换**：任务可配置备用账号有序列表，主账号失效 / 配额满 / 风控时自动切换下一个并落日志通知；全部不可用则标记"待处理"而非丢弃；切换不改变保存目录与命名规则。
- **下载队列持久化与断点续传**：在途下载落库，后端重启后自动恢复；内置下载器支持基于 Range 的续传，记录已验证字节数，重启从断点继续；`.part` 残留可识别接管，校验失败整片重下并标注原因。

## 对话式助手增强

- 复合意图处理：搜索 → 打开 → 归纳一气呵成，不再只罗列链接；缺账号时标注"从标题推断"。
- 操作类默认给出最优默认值（起始/结束集、保存目录自动补全、建后是否立即跑），用户只需修改有改动的部分；动作卡字段中文化。
- 保存目录提供默认值与选择器，并区分桌面与 Compose 部署方式。
- 时间格式统一为 `yyyy-MM-dd hh:mm:ss`。
- 接入真模型（OpenAI 兼容 / Anthropic，可接本机 Ollama 等）。

## 升级注意

1. **凭据自动加密迁移**：首次启动 0.2.0 会把历史明文 Cookie 自动加密；升级前建议先用新备份功能导出一份"不含凭据"备份。
2. **备份文件即凭据面**：含凭据备份含加密 Cookie，请设置访问口令并妥善保管；旧版 `data/*.db` 手动拷贝仍可能含明文，请尽快用 0.2.0 迁移。
3. **通知分级**：既有通知渠道默认归为"仅告知"；需要"需处理"类提醒（失效 / 凭据过期 / 磁盘不足）保持默认开启。
4. **总览首页**：登录后默认进入 `/overview` 总览页，旧的任务页入口保留。
5. **数据目录与下载语义**：三端（Compose / Windows / macOS 客户端）保持一致；本版未改动数据库主键结构，升级向下兼容。

## 已知边界（本期未做）

- **FR-11 SQLite WAL 与写保护**：按规划推迟至 v0.3 / v0.4 作为技术底座项处理；本期下载落库仍走默认 journal 模式，备份走 `VACUUM`-style 一致性导出（见备份功能）。
- 仍为单网盘（夸克）可用；其余网盘为未实现骨架。
- 桌面端无托盘 / 自启 / 自动更新 / 远程模式；包未做发行者签名与 Apple 公证（计划在 v0.3）。
- 公开搜索源、网盘接口与通知服务属外部依赖，连通性 / 限速 / 权限以各自服务为准。
