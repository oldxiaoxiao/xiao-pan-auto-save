# 小盘自动转存 0.3.0 · 开箱即用

> 主题：**客户端用户不必再自己安装 aria2c**，并修掉两个影响日常使用的缺陷。

## 桌面客户端现在有两个版本

每个平台都提供两个包，**功能完全一致**，只差是否随包自带 aria2c：

| 变体 | 文件名特征 | 说明 | 适合 |
|---|---|---|---|
| **完整版** | 带 `-aria2` 后缀 | 随包自带 aria2c，解压即用 | 大多数用户（尤其客户端用户） |
| **精简版** | 无 `-aria2` 后缀 | 不随包，与 0.2.1 行为一致 | 已有自己的 aria2、在意体积、或不愿随包 GPL 二进制 |

体积（zip，spike 实测）：macOS arm64 +2.0MB、macOS x64 +2.1MB、Windows x64 +2.5MB。

**完整版怎么用**：在「设置 → 下载到本地」把模式切到 Aria2 RPC 即可。程序会自动拉起随包的
aria2c（RPC 地址留空则自动用 `127.0.0.1:6800`，只监听本机），**不需要下载、解压、安装，也不需要
理解什么是 RPC**。精简版没有随包二进制，同一页面提供「一键安装 aria2c」（Windows 取官方包 /
macOS 走 Homebrew）。

两个变体共用同一份代码与数据目录，换包不会改动已有任务与数据。

## 修复

- **「重新下载」点了没反应**：此前若驱动不可用、没有可用账号或驱动不支持下载，重下任务只在日志里
  记一行就结束——界面先弹「重下已开始」，之后毫无变化，永远解释不了原因。现在改为：路由层先做校验，
  不可用就**当场报出具体原因**（如「无法重下：没有可用的 quark 账号」）；后台若仍起步失败，也会
  **落一条带原因的失败记录**，历史页看得见。
- **点击后界面卡死（点任何选项都没反应、但能关窗口）**：根因是客户端请求**没有超时**，请求一旦挂起，
  加载蒙层就一直盖在界面上，导致所有点击失效（窗口是系统级的，所以还能关）。现已加入超时保护，
  超时会给出明确提示并撤掉蒙层，界面恢复可用。

## 升级注意

1. **Aria2 地址现在可以留空**：此前必须手填 RPC 地址；现在留空会自动使用 `127.0.0.1:6800` 并按需拉起。
   已手工配置过的地址保持原样，仍优先连接现有 aria2。
2. **自动拉起只监听本机**：随包/托管的 aria2 带 `--rpc-listen-all=false`，不会把 RPC 暴露到局域网。
   远端地址（非 `127.0.0.1` / localhost）不可达时不会在本机乱起 aria2，只如实报错。
3. **程序只管理自己拉起的 aria2**，退出时回收；你自己已有的 aria2 不受影响。
4. 本版未改动数据库主键结构，升级向下兼容。

## 已知边界（本期未做）

- 客户端**常驻体验**（托盘、"关闭窗口"与"退出程序"语义分离、开机自启、桌面通知）仍在规划中。
- **分发与更新基础**（版本检测、下载校验、升级前自动备份）尚未实现；签名与公证也未做，
  包仍无发行者签名与 Apple 公证。
- **FR-11（SQLite WAL 与写保护）**继续顺延至 v0.4。
- 仍为单网盘（夸克）可用；其余网盘为未实现骨架。桌面端不出 Linux 包，Linux 请用 Compose 的 aria2 profile。

## 许可说明

完整版随包的 aria2 为 **GPL-2.0-or-later**（本项目为 AGPL-3.0-only）。若你更倾向于不随包 GPL 二进制，
请选择**精简版**。
