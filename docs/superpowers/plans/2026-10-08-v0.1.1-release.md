# 0.1.1 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan inline; request one independent final review before publishing.

**Goal:** 核查和修复现有功能，交付 Compose、Windows、macOS 三种 0.1.1 发行形式和完整分层文档。

**Architecture:** 保留共享 Vue/FastAPI/SQLite 业务层，桌面壳负责用户数据目录、本地子进程和原生窗口；服务端统一实现登录。各平台原生 runner 编译，统一 GitHub Release 发布附件。

**Tech Stack:** Python >=3.11、Vue 3、FastAPI、pywebview、PyInstaller、Docker Compose、GitHub Actions。

**Spec:** docs/superpowers/specs/2026-10-08-v0.1.1-release-design.md

## Global Constraints

- 版本号 0.1.1，标签 v0.1.1；夸克以外驱动只标为计划支持。
- 验证和构建不得读写真实 data/；制品不得包含 Cookie、数据库、日志。
- 桌面仅监听 127.0.0.1，随机端口和凭证，数据不放安装目录。
- 首版不实现托盘、自启、自动更新和同步。

## Review Focus

- 登录密码保护全部管理接口，外部 Token 不被登录逻辑干扰，SSE 和静态资源可用。
- 冻结程序动态驱动、静态前端、时区数据和 GUI 依赖均进入制品。
- 桌面服务启动失败、重复启动、窗口关闭和 Unicode 数据目录得到正确处理。
- 两种部署形式的下载路径必须属于持久用户数据，升级不覆盖数据库。
- 文档与制品实际能力一致，跳过测试不被写成已验证。
