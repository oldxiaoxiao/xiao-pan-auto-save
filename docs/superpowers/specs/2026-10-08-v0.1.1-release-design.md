# 0.1.1 三端交付设计

用户要求：梳理 Compose 和客户端所需工作与差异，核查全部已有功能，重写项目首页并拆分文档，编译发布 0.1.1。用户进一步确认本次同时交付 Windows 和 macOS 客户端。

## 交付范围

- 一套 Vue 3 界面、FastAPI 服务、SQLite 数据和网盘驱动，三个发行形式共用业务实现。
- Compose 保留源码构建、可选 Aria2、持久数据挂载，增加可重复构建和版本化发布。
- 桌面采用 pywebview 原生窗口和独立 Python 服务子进程，PyInstaller 打包；Windows 便携 ZIP、macOS 应用 ZIP。首次版不内置 Aria2。
- 客户端使用系统用户数据目录和随机本地端口，启动前检查单实例，通过随机启动凭证换取浏览器会话；只监听 127.0.0.1。关闭窗口退出服务并提示正在运行的任务会中止。
- 0.1.1 不承诺托盘驻留、开机自启、自动更新、跨设备同步；明确列为下一阶段。
- 发布前修复已发现的 WEBUI_PASSWORD 未生效，提供浏览器登录会话及 CLI Basic 鉴权，外部 API 继续独立使用 Token。
- 只有夸克是已实现网盘；其他驱动标为计划支持。公开搜索源、真实网盘 Cookie、通知渠道属于外部服务，需要区分自动测试与真实账号验证。
