# 小盘自动转存 0.3.1 · 客户端常驻

> 主题：**客户端可以常驻后台了**——关闭窗口不再等于退出程序，追更和下载继续跑。

## 关闭窗口 ≠ 退出程序

此前关掉窗口就会停掉本地服务、调度和正在进行的下载，想让它后台追更只能一直开着窗口。现在分成两件事：

| 操作 | 行为 |
|---|---|
| **关闭窗口** | 隐藏到系统托盘，**定时追更与正在进行的下载继续运行** |
| **托盘 → 退出程序** | 真正结束：停止本地服务、调度和当前下载 |

- 托盘图标在 Windows 通知区 / macOS 菜单栏；点「打开界面」可随时把窗口调回来（Windows 下单击图标同效）。
- 关闭窗口时不再弹出确认框——关闭已经变成隐藏，每次弹确认是多余的打扰；真正的退出有明确的菜单项。
- 实例锁不变：**同一个数据目录仍只允许一个客户端实例**，开机自启也不会产生第二个实例。

## 开机自启与桌面通知

新增「设置 → 客户端」分组：

- **开机自启**：按平台走原生机制——Windows 启动目录快捷方式、macOS `LaunchAgents`、Linux `~/.config/autostart`。可随时关掉，重复设置是幂等的。
- **桌面通知**：macOS `osascript` / Windows 托盘气泡 / Linux `notify-send`，页面里可发一条测试通知确认能用。

这两项**只在桌面客户端生效**。Compose 版与服务端会如实显示不可用并说明原因，而不是给一个按了没反应的开关。

## 工程侧：补上了打包验证的缺口

托盘只在图形界面模式下启动，而此前的打包冒烟测试跑的是服务模式——**打包产物里托盘到底能不能用，从来没有检查覆盖过**。这类缺陷（pystray 按平台动态导入后端，PyInstaller 静态分析抓不到；或图标资源没入包）会一路带到用户机器上才暴露。

现在冒烟测试会在打包产物里执行托盘自检（导入 pystray 及其平台后端、定位并解码图标、构造菜单），任一项不通过就让构建失败。三个平台的六个包都已通过。

## 修复与稳定

- 修正 `dev` 依赖缺 `pillow`，托盘用例此前在 CI 里因 `ModuleNotFoundError` 失败。
- 根治长期随机失败的调度器用例（约五成概率红、反复阻塞发版）：改为自带绑定当前事件循环的调度器，断言从"恰好一次"放宽为"确实被驱动"。

## 升级注意

1. 想让客户端后台追更，**直接关闭窗口即可**，不用再保持窗口打开。
2. 要彻底退出请走**托盘 → 退出程序**；直接杀进程仍会中断下载（内置下载可能留下 `.part`）。
3. 开机自启按当前程序路径写入；**移动或重装客户端后需要重新开启一次**自启。
4. 本版未改动数据库主键结构，升级向下兼容。

## 已知边界（本期未做）

- 客户端常驻里的**原生目录选择**与**打开文件所在目录**尚未实现。
- **分发与更新基础**（版本检测、下载校验、升级前自动备份）尚未实现；签名与公证也未做，包仍无发行者签名与 Apple 公证。
- **FR-11（SQLite WAL 与写保护）**继续顺延至 v0.4。
- 仍为单网盘（夸克）可用；其余网盘为未实现骨架。桌面端不出 Linux 包，Linux 请用 Compose 的 aria2 profile。
